# Articolo MuonScope

Lavoro in LaTeX: `muonscope.tex` con bibliografia `bibliografia.bib`.

Compilazione:

    pdflatex muonscope
    bibtex muonscope
    pdflatex muonscope
    pdflatex muonscope

Struttura: 1) introduzione, 2) base teorica, 3) attuazione sperimentale di test (3.1 circuito di test e motivazioni, 3.2 risultati sperimentali da completare), 4) realizzazione del MuonScope.

Le parti da completare sono evidenziate in rosso nel PDF (comando `\dadefinire`).

Bibliografia: solo fonti verificate (catalogo editore, DOI o arXiv). Le stime numeriche della sezione 2 (spessore svuotato del BPW34, ENC) sono calcoli propri a partire da datasheet e formule citate, da confermare con le misure della sezione 3.2.
